# Contributing to Plokee

Thank you for your interest in contributing to Plokee!

## Before You Start

- Search existing issues before opening a new one.
- For large changes, please open an issue first to discuss the proposed implementation.

## Reporting Bugs

When reporting a bug, please include:

- Operating system and version
- Plokee version
- Steps to reproduce
- Expected behavior
- Actual behavior
- Screenshots or logs (if available)

## Suggesting Features

Feature requests are welcome.

Please explain:

- the problem you're trying to solve;
- your proposed solution;
- possible alternatives.

## Development

Requirements:

- Flutter (latest stable)
- Dart SDK
- Android Studio or Xcode (depending on the platform)

Clone the repository:

```bash
git clone https://github.com/kvlkstudio/Plokee.git
cd Plokee
flutter pub get
```

Run the application:

```bash
flutter run
```

## Pull Requests

Before submitting a pull request:

- keep changes focused on a single topic;
- follow the existing coding style;
- ensure the project builds successfully;
- update documentation if necessary.

## Commit Messages

Use clear commit messages.

Examples:

```
Fix clipboard synchronization on Android
```

```
Add Linux file transfer support
```
