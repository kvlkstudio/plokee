# Security Policy

## Supported Versions

The latest release is supported with security updates.

| Version | Supported |
|----------|-----------|
| Latest   | ✅ |
| Older    | ❌ |

## Reporting a Vulnerability

If you discover a security vulnerability, please do not create a public GitHub issue.

Instead, contact:

- Email: dev@kvlkstudio.com
- GitHub: https://github.com/kvlkstudio/plokee/security/advisories/new

Please include:

- affected version
- operating system
- steps to reproduce
- proof of concept (if available)

We'll acknowledge reports as soon as possible and work on a fix before public disclosure.
