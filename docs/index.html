Built for fast sharing without handing your clipboard to a cloud.

Plokee keeps the workflow simple: pair trusted devices, keep sync enabled, and copy normally.

T

Text, images, and files

Send plain text, PNG images, and files up to 32 MB per clipboard item.

D

Automatic discovery

Devices find each other on the local network using Bonjour/mDNS and UDP multicast.

P

Simple pairing

Compare the same six-digit code on both screens before trusting a new device.

H

Local history

Keep the latest 100 clipboard items on the current device for quick reuse.

M

Mobile aware

Works within Android and iOS clipboard limits, with foreground and manual-send flows.

S

Tray controls

Desktop builds keep running from the tray with status, recent items, and sync toggles.

Four steps from copy here to paste there.

No sign-in flow or hosted relay is involved. Plokee talks directly to paired devices.

Security model designed for trusted local devices.

X25519 pairing

Devices establish a shared secret with ECDH key agreement.

AES-256-GCM payloads

Clipboard contents are encrypted between paired devices.

HKDF per-pair keys

Transport keys are derived from the pairing secret for each device pair.

HMAC handshake

Connections use challenge-response authentication before syncing.

Network requirements and limits are explicit.

Plokee is built for local-network use, so firewalls and guest Wi-Fi isolation matter.

Allow local discovery and sync

UDP multicast 224.0.0.167:45654, Bonjour/mDNS service _plokee._tcp, and TCP ports 45655-45675.

Know the current boundaries

Files larger than 32 MB are not transferred, and mobile background clipboard access is limited by the OS.
